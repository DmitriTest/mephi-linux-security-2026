Пояснения к артефактам

`history.out` объединяет команды пользователей `dmitri` и `user1`. Две команды мониторинга `ps`, выполненные во втором терминале, восстановлены из `~/.bash_history` и добавлены в конец файла. История собрана из нескольких сеансов; порядок блоков не отражает общую хронологию выполнения команд.

В публикуемой копии `shadow` **второе поле каждой строки заменено на `****`**. Остальные поля сохранены, в том числе максимальный срок действия пароля `user1` — 90 дней. Маскировка выполнена только в копии для публикации; системный `/etc/shadow` не изменялся.
Правило для `user1` находится в отдельном файле `user1-time`, поэтому этот файл приложен вместе с основным `sudoers`.
`find.out` содержит стандартный вывод поиска. Диагностические сообщения `find` о недоступных или исчезнувших путях остались в терминале.
Опубликованные системные файлы являются копиями для проверки домашнего задания.
